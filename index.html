Project goals

An ECCRS classifier explains each prediction by pointing at the rule that decided it. We asked whether those explanations are formally sound: does each prediction actually follow from the rule set under KLM defeasible reasoning?

  • Translate ECCRS rule sets into KLM knowledge bases.
  • Implement Rational Closure, Lexicographic Closure and System W.
  • Compare every prediction against the classifier, instance by instance.

Background

Rule-based explanations

Classifiers make high-stakes calls such as loans and diagnoses, and people need to know why. Rule-based classifiers learn IF-THEN rules from data, so every prediction comes with the rule that made it. When rules conflict, ECCRS lets the most specific rule win (MSW).

Defeasible reasoning

Defeasible reasoning is the formal logic of exceptions: birds typically fly, penguins are birds, penguins don't fly. Madzime and Meyer proved that, under three structural assumptions, MSW gives the same answers as KLM defeasible entailment. We test that claim on real rule sets.

The workbench

A C workbench checks the three assumptions, runs MSW inference with an explanation trace for every instance, translates the rule set into a KLM knowledge base, and asks each closure whether the instance entails m or ¬m. The two sides are then compared side by side.
